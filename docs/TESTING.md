# Testing

Unit tests cover ARR calculation, price delta, feature loss, business-critical loss, renewal risk, contract risk, health risk, support burden, churn scoring, migration difficulty, revenue impact, recommendation, strategy comparison, simulation summary, report generation, and CSV validation.

Integration tests cover scenario creation/running, CSV import validation, and rerunning with changed risk weights.

The E2E test opens the dashboard, creates a simulation, views results, and opens the report.
