# PRD

## Objective
Help Product Managers evaluate pricing and packaging migrations before launch.

## Target Users
SaaS PMs, Growth PMs, Monetization PMs, founders, RevOps, and Customer Success leaders.

## Problem
Teams cannot easily see affected customers, feature loss, contract restrictions, renewal timing, churn risk, or migration strategy trade-offs.

## User Stories
- As a PM, I can load demo or imported data.
- As a PM, I can create a scenario and run a simulation.
- As a CS leader, I can identify high-risk accounts.
- As a founder, I can compare ARR uplift against churn risk.

## Acceptance Criteria
Users can log in, inspect dashboard metrics, upload CSVs, review customers/plans/features, run simulations, compare strategies, configure risk weights, and generate a report.

## Metrics
North star: affected customers migrated without churn or escalation. Supporting metrics: ARR uplift, high-risk accounts, critical feature loss, grandfathering candidates, migration readiness, and confidence score.

## Risks
Risk scoring needs historical calibration, contract rules may vary by company, and integrations are out of MVP scope.

## Open Questions
Which billing and CRM systems should be first integrations? Should Enterprise-only features also be purchasable as add-ons?
